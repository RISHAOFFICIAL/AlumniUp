# AlumniUp Lo-fi Prototype (Stage 4)

Status: APPROVED by Risha, October 19, 2026.
Process: Risha's App Building Playbook, Stage 4.
Grayscale wireframes: layout, order, and tap targets only.
No branding, no color, no final polish (that is Stage 5).

## What is here

- `svg/` — one SVG per screen, S1 to S16, matching the screen
  numbers in the Stage 3 flows (03-flows/user-flow.md). Text is
  real text, so the SVGs stay editable.
- `png/` — the same 16 screens as pictures, for quick review.
- `contact-sheet.png` — all 16 screens on one page.
- `figma-plugin/` — a Figma plugin (manifest.json + code.js) that
  draws all 16 screens as native, editable Figma frames.

Everything was generated by one tool, the wireframes CLI at
~/workspace/tools/wireframes/ (`node wf.js build`), from one data
file (screens.js). The SVG, the PNGs, and the Figma plugin all come
from the same layout data, so they can never drift apart. Change a
screen in the data, rebuild, and all three outputs update.

## Getting the wireframes into Figma (Risha's steps)

1. Create a free account at figma.com (Sign up with Google is fine)
   and create a new design file named "AlumniUp".
2. In that file: menu (top left) → Plugins → Development →
   "Import plugin from manifest..."
3. Choose `figma-plugin/manifest.json` from this folder (download
   the 04-lofi folder from GitHub first, once it is pushed).
4. Run it: Plugins → Development → "AlumniUp Wireframes".
   It draws all 16 screens on the canvas as editable frames.
5. Alternative without the plugin: drag the files from `svg/`
   straight into the Figma canvas. They arrive as editable vector
   groups.

## Layout rules checked at this stage

- Every primary action is at least 44pt tall (buttons are drawn
  48pt). Chips and bars are information, not tap targets.
- Donate is a sheet over the need (S4), not a page change, so the
  donor never loses the need they were reading.
- Primary navigation is a three-tab bar (Home, Honor, Schools);
  portal and admin screens keep their own labeled headers.
- The money trail (S3) is a first-class section of the need page,
  not a footnote: Live, Funded, Sent, Received with dates.

Apple design check 1 (per playbook): the components used here map
to HIG topics Tab Bars, Sheets, Lists, Buttons, and Text Fields.
Their layout consequences are the rules above (tab bar for primary
navigation, sheets for the focused donate task, 44pt targets).
These same components get the full HIG treatment again at Stage 5,
where the Liquid Glass styling is applied.
